# Headcount & People Cost Agent System

Three-agent AI system for headcount planning, compensation analysis, and
people cost forecasting. Built on Anthropic Claude as a consulting portfolio
piece for CFOs, CHROs, and FP&A leaders.

Compensation typically represents 60–70% of a company's operating cost base
and is the hardest line item to forecast accurately. This system surfaces
variances, flags pipeline risk, and identifies comp outliers before they
become budget problems.
